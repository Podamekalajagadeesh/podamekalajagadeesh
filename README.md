## 🚀 Featured Projects

### 1. FundChain — Full-Stack Web3 Crowdfunding

A full-stack crowdfunding platform integrating Ethereum smart contracts, wallet authentication, and database persistence.

- Create campaigns, contribute ETH, withdraw eligible funds, and support contributor refunds.
- Includes wallet-signature authentication, REST APIs, PostgreSQL, Prisma, and blockchain event synchronization.
- **Tech:** Solidity, Hardhat, Next.js, React, Node.js, Express.js, PostgreSQL, Prisma, ethers.js.

🔗 [Source Code](https://github.com/Podamekalajagadeesh/Fundchain) · [Live Demo](https://fundchain-theta-kohl.vercel.app/)

### 2. TokenVest — Token Vesting dApp

A decentralized token-vesting application for managing scheduled token releases.

- Supports cliff and linear vesting schedules, token claims, and revocation.
- Includes administrator and employee dashboards.
- **Tech:** Solidity, OpenZeppelin, Hardhat, React, ethers.js, MetaMask.

🔗 [Source Code](https://github.com/Podamekalajagadeesh/token-vesting-dapp) · [Live Demo](https://tokenvest-bice.vercel.app/)

### 3. Web3 Crowdfunding dApp

A decentralized crowdfunding application deployed on the Sepolia test network.

- Campaign goals and deadlines, ETH contributions, creator withdrawals, and contributor refunds.
- Smart-contract testing with Hardhat.
- **Tech:** Solidity, Hardhat, React, Vite, ethers.js, MetaMask.

🔗 [Source Code](https://github.com/Podamekalajagadeesh/crowdfunding-dapp) · [Live Demo](https://crowdfunding-dapp-lilac.vercel.app/) · [Contract Verification](https://sourcify.dev/server/repo-ui/11155111/0xe39b32a4998B929E3874A4460cA628e14BE62041)
